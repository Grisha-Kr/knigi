# Библиотека — заметки для Claude

Домашняя электронная библиотека: книги (PDF, EPUB, DjVu), полки, читалка PDF, заметки и уроки. Владелец: Григорий (GitHub: Grisha-Kr). Пользователи: он и близкие, до 5 человек, регистрация по приглашению. Адрес: `https://knigi.grishaweb.ru`. Репозиторий открытый: **книги, тексты книг и файлы уроков в него не класть никогда**.

Устройство повторяет «Молитвенный дневник» (Grisha-Kr/molitva): приглашения, письма (правки 2.2), защищённые ссылки на файлы с кукой (правки 2.3), загрузка своим маршрутом, файлы вне `pb_data`.

Этапы. Этап 1 (сделан): книги, полки, загрузка, читалка PDF, заметки и уроки, файлы уроков, «Видна всем», извлечение текста PDF, подпись, журнал, ограничение скорости. Правки 1.1 (сделаны): заметка и урок на весь экран, подсказки у кнопок редактора, новый значок, фото профиля. Этап 2 (сделан): выделения в тексте цветом с мыслью (у читателей тоже), «Маркер» для телефона, читалка EPUB, одна карточка для нескольких форматов книги (объединить, добавить и убрать формат). Правки 2.2 (сделаны): отметки «Читаю» и «Прочитано», книги от читателей с проверкой, поиск в адресе, профиль по фото вместо пункта меню, маленькая кнопка загрузки. Этап 3: удалённый MCP-сервер для claude.ai (поиск книг, текст по страницам, заметки). Позже: DjVu, распознавание сканов.

## Текст книг (для этапа 3)
Текст лежит у каждого файла: `text/ID_ФАЙЛА.txt`. Основной текст книги: `text/<books.text_file>.txt` (PDF с текстом, иначе EPUB). У книг этапа 1 id файла = id книги.
- PDF (`pdfText`): вывод `pdftotext -enc UTF-8` разбит по `\f`, каждая страница начинается строкой `=== Страница N ===`, потом текст, пустая строка. N = номер страницы PDF (как в читалке и в `notes.page`). Пустые страницы тоже есть. `book_files.has_text` = страниц с текстом (не меньше 30 знаков без пробелов) не меньше 20%.
- EPUB (`epubText`): разделы в порядке чтения (spine), каждый начинается строкой `=== Раздел N: название ===` (название из оглавления nav/NCX, иначе из первого заголовка). Текст без тегов, абзацы через перевод строки. has_text = не меньше 500 знаков без пробелов.
- Файла нет, если текста нет. DjVu пока без текста.

## Логика на сервере (pb_hooks)
- `main.pb.js`: хуки и маршруты. `lib.js`: роли, авторы, полки, заметки (`cleanHtml`, `plainText`, `checkNote`), регистрация, письма. `files_lib.js`: папки, ключ, кука и ссылки, Range, лимит, журнал, загрузка частями, обработка, обложки, удаление книги. В обработчиках код верхнего уровня недоступен: `require(`${__hooks}/lib.js`)` внутри.
- Регистрация: первый `role=admin`, остальные по коду `invite`.
- **Загрузка** (admin): `POST /api/knigi/upload/start {name, size, kind: book|file, note, book}` (book = добавить формат к этой книге; второй файл того же формата отклоняется) → `{upload, chunk: 8 МБ, chunks}` (проверка расширения, размера: книга 500 МБ, файл урока 50 МБ, свободного места `size*2` против `MIN_FREE_GB`); `POST /api/knigi/upload/{up}/{n}` multipart `chunk` (размер куска проверяется, повтор перезаписывает); `POST .../finish` склеивает (`cat`) и создаёт `books` + `book_files` (status processing, название и авторы из имени «Автор - Название»), только `book_files` (новый формат) или `note_files`; ответ `{id: книга, file, kind}`; `DELETE /api/knigi/upload/{up}`. Куски по 8 МБ нужны, чтобы одна загрузка не упиралась во время одного запроса и не держала память.
- **Книги от читателей** (правки 2.2, `finishOffer`, `approveOffer`, `rejectOffer` в files_lib.js): `upload/start {kind: offer, note}` только не-администратору, `OFFER_MAX` = 3 (на проверке плюс загружаемые сейчас, проверка при start и finish); куски, finish и отмена загрузки offer разрешены владельцу загрузки. finish склеивает, считает sha256: совпал с файлом обычной книги → файл удаляется, ответ `{duplicate: {id, title}, message}`; с файлом книги на проверке → `{pending: true, message: «Эта книга уже на проверке.»}`; иначе books (pending, offered_by) + book_files (processing, hash) + book_offers, письмо администратору (`mailNewOffer`, не чаще раза в час по `mail_log.kind = offer`). `POST /api/knigi/process` доступен любому вошедшему (только запускает очередь). `POST /api/knigi/offers/{id}/approve {shelves}` (admin, не во время обработки, не при ошибке): pending false, файлы пересохраняются (живое обновление у читателей), полки только общие. `POST .../reject {reason}` (причина обязательна): offer rejected, книга удаляется `deleteBook` (файлы, текст, обложка, авторы без книг). Письма человеку `mailOfferDecision` (`offer_ok`, `offer_no`). Письма уходят, только если в настройках включён SMTP (`mailReady`, `GET /api/knigi/admin/mail`). Удаление книги на проверке из карточки ставит offer rejected «Администратор удалил книгу.».
- **Обработка** (`processQueue`, `processFile`): блокировка через `$app.store().setFunc("kn_proc")`, по одному файлу, пока есть `book_files.status = processing`; после файла `syncBook`. Запуск: `POST /api/knigi/process` (приложение зовёт сразу после загрузки), cron `knigi_process` каждую минуту. PDF: sha256 исходника, `pdfinfo` (страницы, Title, Author; год не берётся), **`qpdf --object-streams=generate --stream-data=preserve`** (см. ниже), обложка `pdftoppm -scale-to-x 400 -jpeg`, текст. EPUB: `unzip -p` container.xml и OPF (title, creator, date, description, обложка → `fs.createThumb` 400x0), текст `epubText`. DjVu: `djvused -e n`, обложка через `ddjvu -format=pdf -page=1` + pdftoppm. Название и авторы из файла ставятся, только если файл у книги единственный, администратор не правил название и имя файла не вида «Автор - Название» (у EPUB свойства важнее). Год и описание, только если пусто. Обложка из файла, только если у книги её нет (обложку из файла делает только тогда). Ошибка → status error у файла, текст в status_note; «Обработать заново» = `POST /api/knigi/books/{id}/reprocess` (все файлы книги).
- **Почему qpdf**: в PDF без потоков объектов (ReportLab, ImageMagick, многие сканы) описание каждой страницы лежит рядом с её картинкой. pdf.js при открытии вызывает `checkLastPage` и при переходе на страницу N перебирает описания всех предыдущих страниц, то есть с загрузкой по кускам скачивает почти весь файл (проверено: 110 МБ при открытии). После `qpdf --object-streams=generate` открытие стоит 1,2 МБ, страница 150 тоже. Линеаризация (`--linearize`) не помогает. Если qpdf не справился, остаётся исходный файл и пометка в status_note.
- **Ссылки и кука** (как материалы «Молитвенного дневника»): `GET /api/knigi/session` ставит куку `kn_s` (JWT {u}, 12 ч, `Path=/api/knigi/f`, HttpOnly, SameSite=Strict, Secure при https/X-Forwarded-Proto). `GET /api/knigi/books/{id}/link?f=pdf|epub` (без f = pdf) → `{url, size, ttl, mark, chunk, file, format, whole}` и та же кука; ключ в адресе (JWT {k, i = id файла, u}, 2 ч). `GET /api/knigi/f/book/{id файла}?t=` проверяет ключ, куку и что человек один; PDF **только Range, не больше 4 МБ** (`MAX_SPAN`), без Range 400; EPUB без Range целиком (до `EPUB_MAX` = 100 МБ, весь размер идёт в лимит и журнал); у не-администратора лимит и журнал; заголовки no-store, octet-stream, inline. Файлы уроков: `GET /api/knigi/files/{id}/link`, `GET /api/knigi/f/file/{id}?t=` (PDF частями; `&dl=1` целиком только владельцу). Обложки: `GET /api/knigi/f/cover/{id}?v=имя` по куке, кэш браузера 30 дней (адрес меняется с обложкой). `POST /api/knigi/logout` стирает куку.
- **Лимит** (`takeBytes`): в памяти (`$app.store`, ключ `kn_rate:user`) два счётчика по часам, прошлый час учитывается долей; сверх `MAX_MB_PER_HOUR` ответ 429 `{message, wait}`. После перезапуска счёт с нуля. На admin не действует.
- **Журнал**: байты пишет маршрут файла книги, страницы пишет `POST /api/knigi/books/{id}/progress {format, page, pages, pct, pos, seen}` (он же сохраняет `reading` этого формата; без format = pdf; у EPUB страницы = локации foliate). `GET /api/knigi/admin/log?days&user&book` (admin). Уборка старше `READ_LOG_DAYS` в cron `knigi_clean` (4:17).
- **Подпись**: `watermarkFor(user)` = «Имя · почта», пусто у admin и при `WATERMARK=0`; рисует клиент на холсте.

## Этап 2: выделения, EPUB, форматы
- **Почему выделения в `notes`**: у заметок уже есть владелец и права, «Видна всем», поиск, раздел «Заметки», «Заметки автора библиотеки»; этап 3 читает одну коллекцию. Выделение = `kind: "highlight"`, quote (выделенный текст целиком), color (yellow/green/blue/pink, `HL` в app.js, `HL_COLORS` в lib.js), body/body_text (мысль), book, format, page (у PDF), place, anchor:
  - PDF: `{v: 1, rects: [[x, y, w, h], …], s, e}`: прямоугольники в долях ширины и высоты страницы (не зависят от масштаба и экрана; куски одной строки склеены, `rangeRects`), s и e: номера первой и последней буквы в тексте страницы pdf.js (`tlRangeText`). Выделение всегда на одной странице: на экране одна страница, продолжение на следующей = отдельное выделение.
  - EPUB: `{v: 1, cfi, pct, chapter}`: место EPUB CFI (foliate `view.getCFI`), процент и глава на момент выделения.
- PDF (`RD.hls`, `rdLoadHls`, `rdDrawHls`): свои выделения книги в формате pdf, слой `.hl-layer` между холстом и текстовым слоем (`mix-blend-mode: multiply`, в «Тёмных страницах» screen), `.hl-tmp` для временной подсветки. Мышь: после отпускания `rdSelCheck` → панель. Нажатие по выделению (`rdHitHl`) → панель правки. Мигание `rdFlash` (класс `.flash`).
- **Панель** `#hl-pop` (`hpShow`, `HP`, `hpAction`): новая: 4 цвета, «Заметка» (жёлтое + окно мысли), у admin «Копировать»; готовая: цвета, «Мысль», удалить (`arm`), «⋯» → «Сделать заметкой» (`hlToNote`: новая заметка с цитатой и местом, выделение остаётся), «Настройки» (admin, «Видна всем»), «Удалить». Нажатие мимо панели только закрывает её (`HP.eat`). Общие выделения администратора у читателей не рисуются, только в списках.
- **Выделение в EPUB на телефоне** (правки после этапа 2): foliate листает EPUB, сдвигая ленту страниц за пальцем, и не знает о выделении. Поэтому, пока на странице есть выделение или включён «Маркер», обработчик `guard` (capture на touchstart/move/end/cancel в документе главы) не пускает касания к foliate: палец и ручки двигают только выделение. Место страницы (`renderer.start`) запоминается в начале такого касания (`EP.hold`) и после отпускания восстанавливается (`epHoldPage`: `scrollBy` на разницу, при неровности `snap`). Касания пальцем (pointerType не mouse) не доходят до foliate как pointerdown/pointerup, иначе он сам листает, когда выделение тянут к краю. PDF: при выделении свайп не листает (`TP.sel`). Ширину колонок и отступы foliate не трогать: при обычном чтении на iPhone страница стоит ровно.
- **Панели читалки**: нажатие в середину страницы прячет и показывает верхнюю и нижнюю панели (`toggleBars`, первые 3 раза подсказка `kn_barsHint`); при каждом открытии книги панели видны (`rdOpenScreen`); при первом открытии EPUB подсказка про середину страницы и «Маркер» (`kn_epHint`). Панель выделения (`hpShow`): выделение в верхней половине экрана, панель под ним; в нижней, над ним (на телефоне отступ 26px под ручки).
- **«Маркер»** (`RD.marker`, `EP.marker`, кнопка `#rd-marker`, есть в панели PDF и EPUB): ведёшь пальцем или мышью, своя подсветка, системного меню нет. PDF: `mkDown/mkMove/mkUp`, буква под пальцем `tlCaret` по прямоугольникам кусков текстового слоя и ширине букв (без caretRangeFromPoint), `touchstart` гасится, листание и нажатия по краям выключены. EPUB: обработчики в документе главы с capture (`epMkDown/Move/Up`), касания не доходят до листания foliate (`guard`, в том числе touchend и touchcancel), буква `epCaret` (caretPositionFromPoint/caretRangeFromPoint, иначе ближайшая буква), в «Маркере» `touch-action: none` в стилях книги. У скана без текста (pdf-файл без has_text) кнопка `.off` и сообщение.
- Список: вкладка «Выделения» в карточке (фильтр цвета `UI.hlColor`, «Только с мыслями» `UI.hlThought`, «ещё» `UI.hlOpen`), `hlRow`, порядок `hlOrder` (формат, страница, процент); в «Заметках» фильтр «Выделения»; ссылка `noteHref` (`&hl=`).
- **EPUB** (`EP`, `epShow`, vendor/foliate): ссылка `?f=epub`, файл целиком `fetch` без кэша (`epFetch`, 429 → `rdPause`), `makeBook(File)`, скрипты книги не загружаются (`transformTarget` 'load' allow=false) и вырезаются из страниц вместе с on*-атрибутами и javascript: (`epClean`): у foliate iframe с allow-scripts и allow-same-origin. Листание foliate (свайп, кнопки, стрелки, нажатие по краям 28%), оглавление `book.toc`, ползунок `goToFraction`, шрифт 4 шага (`kn_epubFont`, `EP_FONT`), тема и шрифт Literata через `renderer.setStyles` (`epStyle`). Прогресс `relocate` → через 1,5 с и при уходе. Выделения через `addAnnotation` / `draw-annotation` (Overlayer.highlight, мигание Overlayer.outline), нажатие `show-annotation`. Подпись читателя: холст `#ep-mark` поверх страниц (`epMarkDraw`, тот же `rdWatermark`).
- **Форматы в клиенте**: `filesOfBook`, `fileOf`, `bookFormats`, `canRead`, `readOf(book, format)`, `readingOf` (последнее чтение), `defaultFormat` (последний прочитанный, иначе PDF с текстом, иначе EPUB, иначе первый), `isScan`. Карточка: переключатель `.fmt-seg` (`UI.cardFmt`), «Продолжить со с. N» / «Продолжить, N%», у DjVu «читалка позже». Обложка: пометка всех форматов, если их больше одного или формат не PDF. Меню книги: «Добавить формат» (`addFormat` → `addUploads(…, book)`), «Объединить с другой книгой» (`mergeBook`), «Убрать формат» (`removeFormat`). Окно после окна: `thenOpen` до `dlg.close()`.
