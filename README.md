# Библиотека

Домашняя электронная библиотека: книги (PDF, EPUB, DjVu), общие и свои полки с подполками, читалка PDF прямо в браузере, заметки и уроки с оформлением текста, файлы к урокам. Пользуются владелец и близкие (до 5 человек), новые пользователи регистрируются только по приглашению. Работает на телефоне и компьютере, ставится на экран как приложение (подпись под значком «Книги»).

Адрес: **https://knigi.grishaweb.ru**

Устроено так же, как «Молитвенный дневник»: одна программа [PocketBase](https://pocketbase.io) (база данных, вход, панель администратора) плюс страницы приложения из папки `pb_public`. Сами книги в репозитории не лежат и никогда не должны в него попадать: код открытый.

```
pb_public/       интерфейс приложения (HTML, CSS, JS, шрифты, значки, читалка pdf.js, редактор Quill)
pb_migrations/   структура базы, правила доступа, письма
pb_hooks/        приглашения, полки, заметки, загрузка и обработка книг, защищённые ссылки, журнал, ограничение
deploy/          установка и обновление на сервере
```

## Установка на сервер

Приложение ставится на тот же сервер рядом с «Зачёткой», «Молитвенным дневником» и «Греческим курсом». Общие настройки Caddy (файл `/etc/caddy/Caddyfile`) установка не меняет.

### Что нужно заранее

В Beget, в DNS домена `grishaweb.ru`, добавлена подзона `knigi` с A-записью `168.113.170.172`. После добавления подождите 15–60 минут.

### Установка одной командой

Подключитесь к серверу (`ssh root@168.113.170.172`) и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/Grisha-Kr/knigi/main/deploy/install.sh | bash -s -- knigi.grishaweb.ru me@grishakr.ru "Григорий Кривобок"
```

Скрипт сам:
- покажет, сколько места свободно на диске;
- поставит нужные программы: `poppler-utils` (обложки, страницы и текст PDF), `qpdf` (пересборка PDF для быстрого открытия), `djvulibre-bin` (страницы и обложка DjVu);
- проверит, что в общем файле Caddy есть строка `import /etc/caddy/sites/*.caddy` (если её нет, остановится и объяснит, что делать);
- проверит, что адрес указывает на сервер;
- скачает код и PocketBase 0.40.3 в `/opt/knigi`, создаст папки `/opt/knigi/books` и `/opt/knigi/files`;
- создаст файл настроек `/opt/knigi/knigi.env`;
- включит автозапуск (служба `knigi`, порт `127.0.0.1:8093`);
- положит файл сайта `/etc/caddy/sites/knigi.caddy` (только TLS 1.2), проверит настройки Caddy; при ошибке уберёт свой файл, другие сайты не пострадают;
- создаст вход в панель администратора PocketBase. Почта и пароль лежат в `/opt/knigi/superuser.txt` (посмотреть: `cat /opt/knigi/superuser.txt`).

### Первый вход

**Сразу после установки** откройте `https://knigi.grishaweb.ru` и создайте аккаунт. Первый зарегистрированный становится администратором; остальные смогут зарегистрироваться только по вашему приглашению.

## Как добавлять книги

1. Главная «Библиотека» → кнопка **«Добавить книги»** (видна только вам).
2. Выберите файлы: можно сразу несколько. Подходят PDF, EPUB и DjVu до 500 МБ каждый.
3. Справа внизу появится окно «Загрузка книг»: у каждого файла своя полоса. Файлы идут по одному, кусками по 8 МБ. Если связь оборвалась, кусок отправляется заново сам. Не закрывайте вкладку, пока идёт загрузка. Окно можно свернуть.
4. После загрузки книга «Обрабатывается»: сервер по одной книге берёт название и автора из свойств файла (или из имени файла), считает страницы, делает обложку из первой страницы, извлекает текст PDF и отмечает «скан без текста», если текста почти нет. Обычно это секунды, у толстой книги до минуты.

Советы:
- Назовите файл **«Автор - Название.pdf»** (через пробел, дефис, пробел): тогда автор и название подставятся правильно, даже если в свойствах файла написано что-то случайное.
- Файл, который уже есть в библиотеке (то же имя и размер), пропускается; кнопка «Всё равно» загрузит его. Если в библиотеке есть точно такой же файл под другим именем, в карточке книги появится пометка «Похоже, это повтор книги …».
- 10-13 ГБ удобно загружать частями, например по папкам, лучше с домашнего Wi-Fi.
- Если на диске сервера свободно меньше 5 ГБ, загрузка отклоняется с объяснением (настройка `MIN_FREE_GB`).

**Данные книги** правите в карточке книги: меню «⋯» → «Изменить данные» (название, авторы через запятую, год, описание), «Заменить обложку» (любая картинка, сервер уменьшит её сам), «Обработать заново» (если что-то не получилось), «Удалить книгу». При удалении приложение спросит, что сделать с вашими заметками и уроками к этой книге: удалить или оставить без книги. Заметки читателей всегда остаются у них, с пометкой «книга удалена».

**EPUB** открывается в своей читалке. **DjVu** можно загружать: у него есть карточка, полки и заметки, читалка появится позже.

## Одна книга в нескольких форматах

У книги может быть по одному файлу каждого формата: PDF, EPUB, DjVu. Название, авторы, описание, обложка, полки и заметки общие. В карточке под названием переключатель «PDF · EPUB»; кнопка «Читать» открывает формат, который этот человек читал последним (в первый раз PDF с текстом, иначе EPUB). Прогресс у каждого формата свой, на главной в «Продолжить чтение» одна карточка с последним форматом.

Всё это в карточке книги, меню «⋯» (только у вас):
- **«Добавить формат»**: выберите файл, он загрузится и обработается как обычно. Название книги не меняется.
- **«Объединить с другой книгой»**: найдите вторую книгу и подтвердите. Остаётся карточка, с которой вы начали; файлы, полки, заметки, уроки, выделения и прогресс всех пользователей переходят в неё, вторая карточка пропадает. Перед объединением приложение покажет, что куда перейдёт. Если у обеих книг файл одного формата, объединить нельзя: сначала уберите лишний.
- **«Убрать формат»**: удаляются файл, его текст, прогресс по этому формату и выделения в нём у всех (приложение скажет, сколько). Последний формат убрать нельзя, для этого есть «Удалить книгу».

## Полки

- **Общие полки** создаёте вы на вкладке «Полки» (кнопка «+ Полка» в блоке «Общие полки»). Их видят все. Дерево до трёх уровней, например «Молитва» → «Классика» → «Баундс и Мюллер». Подполка: откройте полку → «⋯» → «Новая подполка».
- **Мои полки** есть у каждого, их видит только хозяин. У вас тоже есть свои личные полки, отдельно от общих.
- Книга может стоять на нескольких полках. Поставить: в карточке книги «На полку» (галочки по дереву) или на полке «Добавить книги» (поиск с галочками). Снять галочку значит убрать книгу с полки, сама книга остаётся.
- Порядок: на вкладке «Полки» кнопка «Порядок», для подполок «⋯» → «Порядок подполок».
- Удалить можно только пустую полку без подполок.

## Читалка

Листание пальцем влево и вправо, нажатием по краям страницы и кнопками внизу; стрелки на клавиатуре. Нажатие на «45 из 120» открывает переход к странице, ползунок внизу тоже листает. Масштаб кнопками, щипком или колесом мыши с Ctrl. Оглавление (если оно есть в файле). Кнопка во весь экран на компьютере. «⋯» → «Тёмные страницы» для чтения в темноте.

Каждый открывает книгу на своей странице: в карточке «Продолжить со с. 45», на главной «Продолжить чтение».

Кнопка **«Заметка»** создаёт заметку к этой книге с номером текущей страницы (в EPUB с главой и процентом). Выделенный текст попадает в заметку цитатой.

### Читалка EPUB

Листание пальцем, нажатием по краям, кнопками и стрелками; ползунок внизу; оглавление; размер шрифта «А−» и «А+» (4 шага); светлая и тёмная тема вместе с приложением. Внизу глава и процент. В карточке книги «Продолжить, 34%».

## Выделения

Выделять может каждый: и вы, и читатели. Каждый видит только свои выделения.

- **На компьютере**: выделите текст мышью, рядом появится панель: 4 цвета (жёлтый, зелёный, голубой, розовый), «Заметка» (выделить и сразу написать мысль), у вас ещё «Копировать».
- **На телефоне**: нажмите в читалке кнопку **«Маркер»** (карандаш) и проведите пальцем по строкам. Листание в этом режиме выключено, выход повторным нажатием. Системного меню «Скопировать» и «Поделиться» при этом нет.
- Нажмите на готовое выделение: сменить цвет, написать или изменить мысль, удалить. В «⋯»: **«Сделать заметкой»** (новая заметка с цитатой и страницей, выделение остаётся) и у вас «Настройки» → «Видна всем читателям».
- В скане без текста выделять нечего: кнопка «Маркер» бледная.
- **Список**: в карточке книги вкладка «Выделения» с фильтром по цвету и «Только с мыслями». Нажатие открывает книгу на этом месте, выделение коротко мигает. Место подписано «PDF, с. 45» или «EPUB, Глава 3 · 41%».
- В разделе «Заметки» фильтр «Заметки / Уроки / Выделения», поиск ищет и в выделенном тексте, и в мыслях.
- Общие выделения (ваши, с «Видна всем») читатели видят в блоке «Заметки автора библиотеки», на страницах книги они у них не рисуются.

## Заметки и уроки

- В карточке книги вкладки «Заметки» и «Уроки» (уроки только у вас). У читателей вкладка «Заметки» со своими заметками и блок «Заметки автора библиотеки» с тем, чем вы поделились.
- Редактор: заголовок и подзаголовок (кнопки «З1» и «З2»), жирный, курсив, подчёркнутый, списки, цитата, ссылка, отмена. У каждой кнопки подсказка при наведении.
- **На весь экран**: значок с двумя стрелками справа в строке кнопок (или «⋯» → «На весь экран»). Меню и всё лишнее прячутся, текст идёт колонкой по центру. Выход: значок «Свернуть» или клавиша Esc. Приложение запоминает выбор на этом устройстве: следующая заметка откроется так же. Заметка, начатая кнопкой «Заметка» в читалке, открывается в обычном виде. Сохраняется сам через полторы секунды после правки (вверху «Сохранено»); черновик сразу пишется и в память браузера, поэтому без связи ничего не теряется.
- Номер страницы в заметке ведёт в читалку на эту страницу.
- **Файлы к уроку**: PDF, DOC, DOCX, PPT, PPTX и изображения до 50 МБ. PDF открывается в читалке, остальное вы скачиваете кнопкой «Скачать».
- **Поделиться** (только вы): в заметке или уроке «⋯» → «Настройки» → «Видна всем читателям». Вверху появится пометка «Видна всем». Читатели видят её только для чтения; у общего урока они открывают PDF-файлы в читалке, остальные файлы им не показываются. Выключите переключатель, и заметка снова только ваша.
- Раздел «Заметки» в нижнем меню: все заметки, уроки и выделения по всем книгам, поиск по заголовку, тексту, цитатам и мыслям (без учёта регистра и буквы ё), фильтр «Заметки / Уроки / Выделения».
- Заметки читателей не видит никто, кроме них самих, в том числе вы в приложении.

## Фото профиля

«Профиль» → нажмите на кружок над именем → «Выбрать фото». В окне передвиньте фото пальцем или мышью, увеличьте ползунком (на телефоне двумя пальцами) и нажмите «Готово». Подходят JPG, PNG, WEBP и HEIC (фото с iPhone) до 15 МБ; на сервер уходит уже обрезанный круг размером около 50-100 КБ. Там же «Убрать фото».

Своё фото видит каждый у себя (в профиле, в шапке на телефоне, внизу бокового меню на компьютере). Вы видите фото всех в «Профиль» → «Пользователи» и у приглашений. Читатели видят только ваше фото, рядом с «Заметками автора библиотеки»; фото других читателей им недоступно.

## Приглашения

«Профиль» → «Приглашения». Укажите, для кого приглашение и сколько человек может по нему зарегистрироваться, нажмите «Создать и скопировать ссылку». Человек откроет ссылку, и код подставится сам.

## Настройки

Файл `/opt/knigi/knigi.env` (у каждой строки комментарий по-русски):

| Настройка | Что делает |
|---|---|
| `APP_URL` | адрес приложения, из него строятся ссылки в письмах |
| `OWNER_NAME`, `CONTACT_EMAIL` | оператор и почта для политики конфиденциальности |
| `BEHIND_PROXY=1` | приложение стоит за Caddy, не менять |
| `BOOKS_DIR` | папка книг (`/opt/knigi/books`), внутри `covers` (обложки) и `text` (текст PDF) |
| `FILES_DIR` | папка файлов уроков (`/opt/knigi/files`) |
| `MIN_FREE_GB=5` | сколько гигабайт оставлять свободными; если меньше, загрузка отклоняется |
| `WATERMARK=1` | подпись на страницах, `0` выключает |
| `READ_LOG=1` | журнал чтения, `0` выключает |
| `READ_LOG_DAYS=180` | сколько дней хранить журнал |
| `MAX_MB_PER_HOUR=200` | ограничение скорости на читателя, `0` выключает |

Открыть файл на сервере: `nano /opt/knigi/knigi.env` (сохранить: Ctrl+O, Enter, выйти: Ctrl+X). После правки:

```bash
systemctl restart knigi
```

Подпись, журнал и ограничение на вас как администратора не действуют.

### Подпись на страницах (`WATERMARK`)

У читателя на каждой странице бледная подпись с его именем и почтой: крупно по диагонали и мелко внизу с датой. Она рисуется прямо на картинке страницы, поэтому видна на снимках и фото экрана и не убирается скрытием элемента страницы.

### Журнал чтения (`READ_LOG`, `READ_LOG_DAYS`)

«Профиль» → «Журнал чтения» (только у вас). Строка на каждый час: читатель, книга, сколько разных страниц открыто, сколько данных книги отдал сервер. Красным отмечены часы, где сработало ограничение или открыто больше 150 страниц. Фильтры по читателю, книге и сроку. Записи старше 180 дней удаляются сами.

### Ограничение скорости (`MAX_MB_PER_HOUR`)

Сервер считает, сколько данных книг он отдал каждому читателю за последний час (по всем книгам вместе). Сверх лимита файл не отдаётся, а читалка показывает «Вы читаете очень быстро. Сделайте паузу и продолжите через N минут». После перезапуска приложения счёт начинается заново.

Сколько это в страницах (проверено на скане в 110 МБ, 300 страниц): читалка берёт куски по 512 КБ, страница такого скана стоит около 0,5 МБ. **200 МБ в час это примерно 400 страниц скана** или любое количество страниц обычной текстовой книги. Обычное чтение, даже быстрое листание, в лимит укладывается, а выкачать за час толстую книгу целиком нельзя. Менять число не нужно. Если у вас будут очень тяжёлые цветные сканы (1,5 МБ на страницу и больше) и читатели начнут видеть паузу, поднимите до 300.

## От чего защищены книги

Есть защита:
- **Скачать книгу нельзя**: в приложении нет кнопок «Скачать», «Печать», «Поделиться», «Открыть в другой программе». Вы тоже скачиваете книги только с сервера (оригиналы у вас на Mac).
- **Файл книги отдаётся только по защищённой ссылке**, PDF только частями (не больше 4 МБ за запрос), EPUB целиком (он небольшой), и весь его размер идёт в ограничение скорости и журнал. Ссылку выдают только вошедшему, она живёт 2 часа и работает только вместе с защищённой кукой браузера, где выполнен вход. Пересланная ссылка у другого человека или в другом браузере не открывается, без входа тоже.
- **Ничего не остаётся в памяти телефона**: файлы книг идут с запретом сохранения, приложение (service worker) их не кэширует. Без интернета книги не открываются.
- **Читатель не может скопировать текст**: выделять для пометок он может, но при копировании (Ctrl+C, меню) в буфер обмена попадает пустая строка, контекстное меню и перетаскивание выключены; на телефоне у читателя обычное выделение выключено, выделяет только «Маркер», поэтому системного меню «Скопировать» и «Поделиться» нет. Вам выделять и копировать можно.
- **Скрипты из EPUB не работают**: читалка их не загружает и вырезает из страниц книги.
- **Печать** выключена: при печати страницы приложения выходит только надпись «Печать отключена».
- **Обложки** открываются только вошедшим.
- **Подпись** с именем и почтой читателя на каждой странице (`WATERMARK`), **журнал** (`READ_LOG`) и **ограничение скорости** (`MAX_MB_PER_HOUR`) делают массовое копирование заметным и медленным.
- Все права проверяет сервер. Читатель не может прямыми запросами загрузить книгу, изменить общую полку, включить «Видна всем», прочитать чужие заметки или журнал (проверено).

Защиты нет:
- **Снимок и запись экрана** запретить в браузере нельзя. Человек может сфотографировать или записать каждую страницу. Подпись на страницах покажет, от кого пришли снимки.
- Человек с навыками программиста, у которого есть вход, может написать программу, которая листает книгу за него. Ограничение скорости и журнал сделают это медленным и заметным, но не невозможным.
- Тот, кому вы дали доступ, видит книгу целиком. Поэтому приглашайте только тех, кому доверяете.

## Установка на телефон и компьютер

- **iPhone** (Safari): откройте сайт → «Поделиться» → «На экран „Домой“».
- **Android** (Chrome): меню из трёх точек → «Установить приложение» или «Добавить на главный экран».
- **Компьютер** (Chrome, Edge, Яндекс Браузер): значок установки в адресной строке справа.

Когда выходит новая версия, вверху появляется плашка «Вышло обновление» с кнопкой «Обновить».

## Обновление

Когда в репозитории появилась новая версия, на сервере выполните:

```bash
bash /opt/knigi/src/deploy/update.sh
```

Скрипт останавливает приложение, сохраняет копию базы в `/opt/knigi/pb_data/backups`, загружает новый код и запускает приложение. В конце он пишет «Готово: приложение обновлено и работает». Если новая версия не запустилась, скрипт вернёт прежнюю версию кода и запустит её.

Чтобы обновить сам PocketBase, поменяйте `PB_VERSION` в `deploy/install.sh` и запустите установку ещё раз с теми же параметрами. Перед этим прочитайте заметки к выпуску: до версии 1.0 в PocketBase бывают несовместимые изменения.

## Резервные копии

- Сервер сам делает копию базы каждый день в 3:00 и хранит 14 последних: пользователи, полки, заметки, уроки, прогресс, журнал. Скачать или восстановить: панель `https://knigi.grishaweb.ru/_/` → «Settings» (настройки) → «Backups» (резервные копии).
- **Книги, обложки, тексты и файлы уроков в эти копии не входят**: они лежат отдельно, в `/opt/knigi/books` и `/opt/knigi/files`, иначе 14 копий по 13 ГБ заняли бы весь диск. Страховка для них: оригиналы книг у вас на Mac (держите там и файлы уроков) и недельная копия всего сервера у хостинга.
- Обновление приложения эти папки не трогает.

## Место на диске

```bash
df -h /
```

```bash
du -sh /opt/knigi/books /opt/knigi/files
```

Первая команда показывает свободное место на диске (60 ГБ на все приложения), вторая сколько занимают книги и файлы уроков. В профиле администратора тоже видно, сколько занимают книги и сколько свободно.

## Почта

Письма «Забыли пароль?» и подтверждение почты на русском, как в «Молитвенном дневнике». Настройки почты задаются в панели `/_/` → «Settings» → «Mail settings» (сервер `smtp.yandex.ru`, порт 465, пароль приложения Яндекса, имя отправителя «Библиотека»). Ограничения: 3 запроса в час с одного адреса в интернете и не больше 5 писем в сутки на одну почту. Сменить почту в приложении нельзя, её меняет администратор в панели.

## Если что-то не работает

```bash
systemctl status knigi
```

```bash
journalctl -u knigi -n 50
```

```bash
systemctl restart knigi
```

Первая команда показывает, работает ли приложение, вторая последние сообщения и ошибки, третья перезапускает. Если книга застряла в «Обрабатывается», откройте её карточку → «⋯» → «Обработать заново».

## Персональные данные

Приложение хранит почту, имя, полки, заметки, прогресс чтения и журнал чтения на сервере в России. При регистрации пользователь даёт согласие на обработку данных, страница политики `/privacy.html`.

## Разработка у себя на компьютере

```bash
./pocketbase serve --http 127.0.0.1:8093 --dir /tmp/knigi/pb_data --publicDir pb_public --hooksDir pb_hooks --migrationsDir pb_migrations
```

Нужны `poppler-utils` и `qpdf`. Файлы книг по умолчанию лягут в `/tmp/knigi/books` (рядом с `pb_data`).
